# Contributing

waydlp is built in the open and contributions of every size are welcome.

## Ways to help

- **Report bugs** with clear steps to reproduce, your platform and the technical details from the error.
- **Suggest features** — explain the problem you want to solve, not just the solution.
- **Improve documentation** — this website's docs are Markdown files in [`content/docs`](https://github.com/waywhywhy/waywhy-website/tree/main/content/docs).
- **Write code** for the [desktop app](https://github.com/waywhywhy/waydlp-desktop-rust), the [Android app](https://github.com/waywhywhy/waydlp-mobile-dart) or [this website](https://github.com/waywhywhy/waywhy-website).
- **Test packages** on your distribution or device and report what works.

## Before you start

1. Read the [organisation contributing guide](https://github.com/waywhywhy/.github/blob/main/CONTRIBUTING.md) and [code of conduct](https://github.com/waywhywhy/.github/blob/main/CODE_OF_CONDUCT.md).
2. For larger changes, open an issue first so we can agree on the approach.
3. Each repository's `CONTRIBUTING.md` explains how to build, test and lint it.

## Ground rules

- No fake functionality: features must really work, progress and metadata must be real.
- No telemetry, ads or required accounts.
- Never run user input through a shell; validate everything user-controlled.
- Keep the AMOLED-black and purple design consistent.
- Add tests, run the linters, and describe how you tested your change.

Security issues go through [private reporting](/security), not public issues.
